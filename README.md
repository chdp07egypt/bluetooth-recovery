# Bluetooth — диагностика и восстановление

Приложение для Windows, без установки дополнительных библиотек.

1. Откройте `start.cmd` и нажмите «Диагностика».
2. Для исправлений закройте окно и откройте `start-admin.cmd`. Подтвердите системный запрос Windows.
3. В приложении записи нажмите «Остановить» и дождитесь сохранения.
4. Нажмите «Восстановить Bluetooth». Проверьте результат в параметрах Bluetooth.
5. Если адаптер присутствует, но завис, используйте «Перезапустить адаптер»: Bluetooth-устройства временно отключатся.
6. Если Bluetooth работает, но нет звука, используйте «Восстановить звук»: звук всех приложений временно прервётся.

Каждая операция сохраняет текстовый отчёт в `reports`. Ошибки доступа отмечаются явно. Исправления сохраняют исходные настройки служб в JSON. Автоматического отката нет: при необходимости исходный тип запуска bthserv можно вернуть через services.msc, сверившись с файлом services-before.json. Приложение не удаляет драйверы, записи встреч или сопряжения, не завершает процессы записи и не перезагружает компьютер.

Успешная команда не гарантирует исправление: подтвердите фактическое подключение мыши или наушников. Остановленная служба с типом Manual сама по себе не доказывает неисправность.

## Если адаптер не обнаружен

Если повторное обнаружение не вернуло адаптер, сохраните работу, полностью выключите компьютер и снова включите. Если проблема останется, проверьте Bluetooth-драйвер для точной модели компьютера на сайте его производителя. Не удаляйте USB-контроллеры или драйверы наугад.
